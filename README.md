# Automated Gambling Player Classification using PL/pgSQL and Machine Learning (K-Means)(STOIXIMATIKH)
Δημιουργήθηκε ένα αυτοματοποιημένο σύστημα το οποίο ξεχωρίζει τους επαγγελματίες παίκτες στοιχήματος από τους ερασιτέχνες Η βάση δεδομένων υπολογίζει αυτόματα το κέρδος και την αξία κάθε στοιχήματος μέσω triggers Στη συνέχεια ο αλγόριθμος KMeans της Python αναλύει αυτά τα δεδομένα και χωρίζει τους χρήστες σε clusters προσφέροντας έλεγχο των Sharps
1. Το Πρόβλημα (The Business Challenge)
Στον χώρο του online στοιχημάτος, οι εταιρείες αντιμετωπίζουν δύο βασικές κατηγορίες παικτών:
Οι Casual (Ψυχαγωγικοί): Παίκτες που ποντάρουν για διασκέδαση. Μακροπρόθεσμα χάνουν, άρα αφήνουν κέρδος στην εταιρεία.
Οι Sharps (Επαγγελματίες): Παίκτες που ξέρουν να εντοπίζουν λάθη στις αποδόσεις. Μακροπρόθεσμα κερδίζουν, άρα αποτελούν οικονομική απειλή.
Το ερώτημα είναι: Πώς μπορεί μια εταιρεία να τους ξεχωρίσει αυτόματα και έγκαιρα, χωρίς να βασίζεται απλά στην "τύχη" (γιατί ένας Casual μπορεί να κερδίσει προσωρινά λόγω τύχης, ενώ ένας Sharp μπορεί να χάσει λόγω ατυχίας);

2. Η Λύση: Το "Έξυπνο" Back-end (PostgreSQL)
Για να λυθεί αυτό, η εργασία χρησιμοποιεί μια βάση δεδομένων PostgreSQL. Αντί να περιμένουμε το τέλος του μήνα για να δούμε ποιος κέρδισε, η βάση παρακολουθεί τους παίκτες σε πραγματικό χρόνο.
Κάθε φορά που ένας παίκτης κάνει ένα στοίχημα, ενεργοποιείται αυτόματα ένας μηχανισμός (Database Trigger γραμμένος σε PL/pgSQL). Ο Trigger αυτός κάνει δύο πράγματα ακαριαία:
Υπολογίζει το Καθαρό Κέρδος (Net Profit): Πόσα χρήματα κερδίζει ή χάνει ο παίκτης.
Υπολογίζει το CLV (Closing Line Value): Συγκρίνει την απόδοση που πρόλαβε ο παίκτης με την τελική απόδοση κλεισίματος της αγοράς. Αν ο παίκτης προλαβαίνει σταθερά μεγαλύτερες αποδόσεις πριν αυτές πέσουν, τότε "νικάει την αγορά".
Όλα αυτά τα στοιχεία αποθηκεύονται και ενημερώνονται αυτόματα στον πίνακα player_stats χρησιμοποιώντας την τεχνική ON CONFLICT ... DO UPDATE, εξασφαλίζοντας τεράστια ταχύτητα και σταθερότητα.

3. Η Ανάλυση: Το Μοντέλο AI (Python & Machine Learning)
Εδώ μπαίνει η Τεχνητή Νοημοσύνη. Ένα script σε Python συνδέεται στη βάση δεδομένων μέσω SQLAlchemy και "διαβάζει" τον πίνακα των στατιστικών.
Επειδή το κέρδος (π.χ. 1000€) και το CLV (π.χ. 0.05) έχουν τελείως διαφορετικά μεγέθη, ο κώδικας εφαρμόζει StandardScaler για να τα φέρει στην ίδια κλίμακα, ώστε ο αλγόριθμος να τα κρίνει δίκαια.
Στη συνέχεια, εφαρμόζεται ο αλγόριθμος Μηχανικής Μάθησης K-Means Clustering, ο οποίος ρυθμίζεται να χωρίσει τους παίκτες σε 2 ομάδες (Clusters):
Cluster 0 (Casuals): Η μάζα των παικτών. Έχουν αρνητικό ή μηδενικό CLV και οι περισσότεροι είναι χαμένοι.
Cluster 1 (Sharps): Μια μικρή ομάδα παικτών που βρίσκονται στο γράφημα πάνω δεξιά. Έχουν σταθερά θετικό CLV και θετικό net profit. Το σύστημα τους "κλειδώνει" ως επικίνδυνους.
