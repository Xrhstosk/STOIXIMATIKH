# STOIXIMATIKH
Δημιουργήθηκε ένα αυτοματοποιημένο σύστημα το οποίο ξεχωρίζει τους επαγγελματίες παίκτες στοιχήματος από τους ερασιτέχνες Η βάση δεδομένων υπολογίζει αυτόματα το κέρδος και την αξία κάθε στοιχήματος μέσω triggers Στη συνέχεια ο αλγόριθμος KMeans της Python αναλύει αυτά τα δεδομένα και χωρίζει τους χρήστες σε clusters προσφέροντας έλεγχο των Sharps
